Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3436954](https://www.drupal.org/node/3436954)

State caching is permanently enabled.

Previously, this was controlled by a setting in settings.php, which is described in the change record, [State service now uses a cache collector for performance](https://www.drupal.org/node/3177901). The setting is now removed.
