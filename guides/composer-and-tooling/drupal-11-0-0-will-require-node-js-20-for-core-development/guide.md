Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3460350](https://www.drupal.org/node/3460350)

Drupal 11.0.0 will now require Node.js 20 for core development. NodeJs 18 will be end of life in April 2025.

This only affects sites that have installed Drupal core's JavaScript development dependencies with npm or yarn.
