Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3215207](https://www.drupal.org/node/3215207), [#3357409](https://www.drupal.org/node/3357409), [#3346338](https://www.drupal.org/node/3346338)

Drupal 11 database requirements have been set as follows.

### MySQL

MySQL/Percona 8.0.

(A [MySQL 5.7 contrib module](https://www.drupal.org/project/mysql57) is under development to add a driver supporting the old MySQL version, but is not officially supported by Drupal core and may have bugs or limitations.)

### MariaDB

MariaDB 10.6.

### PostgreSQL

PostgreSQL 16.

### SQLite

SQLite 3.45.

Read [Database server requirements](https://www.drupal.org/docs/getting-started/system-requirements/database-server-requirements) for more details.
