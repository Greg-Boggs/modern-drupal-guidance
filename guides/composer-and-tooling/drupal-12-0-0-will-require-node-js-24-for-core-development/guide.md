Introduced in version: 12.0.0\
Issue links: [#3620803](https://www.drupal.org/node/3620803)

Drupal 12.0.0 will now require Node.js 24 for core development. NodeJs 20 was EOL was April 20, 2026

This only affects sites that have installed Drupal core's JavaScript development dependencies with npm or yarn.
