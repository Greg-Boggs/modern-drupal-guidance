Introduced in version: 12.1.0\
Issue links: [#3594336](https://www.drupal.org/node/3594336)

The following commands for extensions are now available for the \`dr\` CLI application. Use run `vendor/bin/dr help [command-name]` to learn about available arguments, options, usage-examples, aliases.

| Command | Options | Description |
| --- | --- | --- |
| ex:list | type format core package installed | List extensions, both installed and uninstalled. |
