Introduced in version: 11.1.0-beta1\
Issue links: [#3483481](https://www.drupal.org/node/3483481)

The Package Manager extension is available for testing only.

To install the extension, `testing_package_manager` must be set to `TRUE` in the site `settings.php` file.

To install:\
`$settings['testing_package_manager'] = TRUE;`
