Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3458167](https://www.drupal.org/node/3458167)

The core `quick-start` command now has a `--password` option to set the password. If the option is not used, then as before this change, a random password is generated.
