Introduced in branch: 11.4.x\
Introduced in version: 11.4.0\
Issue links: [#3566600](https://www.drupal.org/node/3566600)

The meta-package `drupal/core-dev-pinned` is deprecated. It will be removed in Drupal 12.

Instead, use the `drupal/core-dev` meta-package. This will allow dependency updates and avoid security vulnerabilities from pinned dependency versions.

*Source: [The drupal/core-dev-pinned metapackage is deprecated](https://www.drupal.org/node/3566742), a Drupal core change record by [quietone](https://www.drupal.org/user/2572884) on drupal.org, licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).*
