Introduced in branch: 11.5.x\
Introduced in version: 11.5.0\
Issue links: [#3572350](https://www.drupal.org/node/3572350)

The default homepage is now `/user`. The Standard profile has set `/node` as the default homepage.

More information is available in the [change notice about changing the "frontpage" view](https://www.drupal.org/node/3612430).
