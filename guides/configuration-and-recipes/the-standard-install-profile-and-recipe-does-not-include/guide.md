Introduced in version: 11.5.0\
Issue links: [#3588274](https://www.drupal.org/node/3588274)

The taxonomy module is still enabled in the Standard install profile and recipe assuming a likely need for content categorization but the default Tags vocabulary is not created anymore in the Standard profile and recipe.
