Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3113989](https://www.drupal.org/node/3113989)

The Media author views filter now uses the `user_name` plugin. This means instead of a normal text field, it is an autocomplete field with typeahead functionality by user name.
