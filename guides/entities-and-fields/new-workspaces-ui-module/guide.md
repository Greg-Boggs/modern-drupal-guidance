Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#2972622](https://www.drupal.org/node/2972622)

A new Workspaces UI module has been added which enables the routes and toolbar integration of the Workspace module. This is to allow for alternative user interface implementations in core or contrib.

The majority of supporting code remains in the Workspaces module for now to minimize disruption for any modules that might integrate with routes or forms etc.

Sites already using Workspaces will have Workspaces Ui module enabled in an update.
