Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3488742](https://www.drupal.org/node/3488742)

When adding a node type via the UI, the node type form automatically created a body field.

This is no longer the case from 11.1.

The body field can be added manually via the 'Re-use field' option in Field UI, or omitted entirely from content types that don't need it.
