Issue links: [#3411839](https://www.drupal.org/node/3411839)

Drupal 11.0.0 will ship with jQuery 4.

See the [jQuery 4.0.0-beta](https://blog.jquery.com/2024/02/06/jquery-4-0-0-beta/) announcement for relevant changes. JavaScript that was already fully up to date with jQuery 3 should be compatible with jQuery 4.
