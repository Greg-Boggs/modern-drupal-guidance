Introduced in version: 12.0.0\
Issue links: [#3572280](https://www.drupal.org/node/3572280)

The Migrate Drupal module is removed.

The Migrate Drupal module was deprecated in Drupal 11.4.0. There is no replacement contributed module.

If you need the functionality provided by the Migrate Drupal module, read the [recommendations for the Migrate Drupal module](https://www.drupal.org/node/3223395#s-migrate-drupal).
