Introduced in branch: 12.0.x\
Introduced in version: 12.0.0\
Issue links: [#3574714](https://www.drupal.org/node/3574714)

The Migrate Drupal UI module is removed.

The Migrate Drupal UI module was deprecated in Drupal 11.3.0. There is no replacement contributed module

Read the [recommendations for the Migrate Drupal UI module](https://www.drupal.org/node/3223395#s-migrate-drupal-ui).
