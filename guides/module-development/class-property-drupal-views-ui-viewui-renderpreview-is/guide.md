Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3477600](https://www.drupal.org/node/3477600)

All usages of the property `ViewUI::$renderPreview` were removed from core before the release of Drupal 8.0.0 in [Entity Forms in ajax requests don't find the route](https://www.drupal.org/project/drupal/issues/1983164). This change is removing the property.

There is no replacement
