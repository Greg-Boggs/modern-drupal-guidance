Introduced in branch: 11.4.x\
Introduced in version: 11.4.0\
Issue links: [#3588276](https://www.drupal.org/node/3588276)

The standard install profile and recipe does not depend on comment module anymore, meaning site builders need to explicitly decide to enable commenting. The feature itself is still available in Drupal core.

*Source: [Commenting is not enabled in Drupal by default anymore](https://www.drupal.org/node/3606437), a Drupal core change record by [gábor hojtsy](https://www.drupal.org/user/4166) on drupal.org, licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).*
