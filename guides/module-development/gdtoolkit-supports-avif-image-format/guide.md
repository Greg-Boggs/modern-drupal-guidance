Introduced in branch: 11.2.x\
Introduced in version: 11.2.0\
Issue links: [#3202016](https://www.drupal.org/node/3202016)

The Drupal core GDToolkit now supports the [AVIF image format](https://aomediacodec.github.io/av1-avif/).

Please note that this requires platform dependencies:

- It requires the PHP GD extension to be based on `libgd` version 2.3.2 or later including `libavif` support. See [https://php.watch/versions/8.1/gd-avif](https://php.watch/versions/8.1/gd-avif) for instructions how to make sure it is added to your installation of PHP.
