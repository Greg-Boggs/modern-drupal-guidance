Introduced in branch: 12.0.x\
Introduced in version: 12.0.0-beta2\
Issue links: [#3627057](https://www.drupal.org/node/3627057)

The navigation top bar feature flag module, which was hidden, obsolete and unpublished in Drupal 11, has now been fully removed from core. The navigation top bar was merged into the navigation module as a non-configurable feature during the Drupal 11 cycle.

*Source: [Navigation top bar feature flag removed from core](https://www.drupal.org/node/3627750), a Drupal core change record by [catch](https://www.drupal.org/user/35733) on drupal.org, licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).*
