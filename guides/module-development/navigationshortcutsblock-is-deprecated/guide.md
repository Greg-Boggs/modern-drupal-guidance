Introduced in branch: 11.5.x\
Introduced in version: 11.5.0\
Issue links: [#3581816](https://www.drupal.org/node/3581816)

The `navigation_shortcuts` block has moved from the Navigation module to the Shortcut module.

Therefore, `\Drupal\navigation\Plugin\Block\NavigationShortcutsBlock` is deprecated. Instead, use `\Drupal\shortcut\Plugin\Block\ShortcutNavigationBlock`.
