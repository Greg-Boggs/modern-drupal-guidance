Issue links: [#3576669](https://www.drupal.org/node/3576669)

Settings Tray has been deprecated and will be removed in 12.0.0

If you want to keep using the functionality provided by Settings Tray, read the [recommendations for Settings Tray](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-settings-tray).
