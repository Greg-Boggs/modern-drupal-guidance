Issue links: [#3594202](https://www.drupal.org/node/3594202)

Telephone is deprecated and will be removed from Drupal 12.0.0.

If you want to keep using the functionality provided by Telephone, [read the recommendations for Telephone](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete#s-telephone).
