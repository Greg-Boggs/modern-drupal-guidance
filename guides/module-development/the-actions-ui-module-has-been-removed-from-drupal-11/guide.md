Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3432134](https://www.drupal.org/node/3432134)

The Actions UI (action) module's code has been removed to contrib as it was [deprecated in 10.3.0](https://www.drupal.org/node/3425074)

You should add a dependency on the [contributed Actions UI module](https://www.drupal.org/project/action) in order to continue using it on Drupal 11.x.

If you want to keep using the functionality provided by the module, read the [recommendations for Actions.](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete#s-actions-ui).
