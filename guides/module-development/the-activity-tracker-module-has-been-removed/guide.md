Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3261452](https://www.drupal.org/node/3261452)

The Activity Tracker module is removed.

The Activity Tracker module was deprecated in Drupal 10.1.0 and the module moved to contrib at [https://drupal.org/project/tracker](https://www.drupal.org/project/tracker).

If you need the functionality provided by the Activity Tracker module, read the [recommendations for the module](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete#s-activity-tracker).
