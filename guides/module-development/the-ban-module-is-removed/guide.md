Introduced in version: 12.0.0\
Issue links: [#3571886](https://www.drupal.org/node/3571886)

The Ban module is removed.

The Ban module was deprecated in Drupal 11.4.0 and the module moved to contrib at [https://drupal.org/project/ban](https://drupal.org/project/ban)

If you need the functionality provided by the Ban module, read the [recommendations for the Ban module.](https://www.drupal.org/node/3223395#s-ban)
