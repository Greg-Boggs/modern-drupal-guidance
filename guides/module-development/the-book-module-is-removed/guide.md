Issue links: [#3423975](https://www.drupal.org/node/3423975)

The Book module is removed.

The Book module was deprecated in Drupal 10.3.0 and the module moved to contrib at [https://drupal.org/project/book](https://www.drupal.org/project/book).

If you need the functionality provided by the Book module, read the [recommendations for the Book module](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-book).
