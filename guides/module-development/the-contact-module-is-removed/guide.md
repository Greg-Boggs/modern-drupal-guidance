Introduced in version: 12.0.0\
Issue links: [#3573484](https://www.drupal.org/node/3573484)

The Contact module is removed.

The Contact module was deprecated in Drupal 11.4.0 and the module moved to contrib at [https://drupal.org/project/contact](https://drupal.org/project/contact)

If you need the functionality provided by the Contact module, read the [recommendations for the Contact module](https://www.drupal.org/node/3223395#s-contact).
