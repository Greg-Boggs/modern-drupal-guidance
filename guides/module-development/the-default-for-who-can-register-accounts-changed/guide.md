Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3453676](https://www.drupal.org/node/3453676)

The default value of the "Who can register accounts?" setting has changed from "Visitors, but administrator approval is required" to "Administrators only".

This only affects *new* sites built with either the "Standard" or "Minimal" installation profile.
