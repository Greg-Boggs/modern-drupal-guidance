Introduced in version: 12.0.0\
Issue links: [#3570668](https://www.drupal.org/node/3570668)

The History module is removed.

The History module was deprecated in Drupal 11.4.0 and the module moved to contrib at [https://drupal.org/project/history](https://drupal.org/project/history)

If you need the functionality provided by the History module, read the [recommendations for the History module](https://www.drupal.org/node/3223395#s-history).
