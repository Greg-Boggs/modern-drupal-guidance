Introduced in version: 12.0.0\
Issue links: [#3586217](https://www.drupal.org/node/3586217)

The Search module is removed.

The Search module was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/search](https://drupal.org/project/search)

If you need the functionality provided by the Search module, read the [recommendations for the Search module](https://www.drupal.org/node/3223395#s-search).
