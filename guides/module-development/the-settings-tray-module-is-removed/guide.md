Issue links: [#3586218](https://www.drupal.org/node/3586218)

The Settings Tray module is removed.

The Settings Tray module was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/settings_tray](https://drupal.org/project/settings_tray)

If you need the functionality provided by the History module, read the [recommendations for the Settings Tray module](https://www.drupal.org/node/3223395#s-settings-tray).
