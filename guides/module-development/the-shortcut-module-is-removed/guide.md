Introduced in version: 12.0.0\
Issue links: [#3586214](https://www.drupal.org/node/3586214)

The Shortcut module is removed.

The Shortcut module was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/shortcut](https://drupal.org/project/shortcut)

If you need the functionality provided by the Shortcut module, read the [recommendations for the Shortcut module](https://www.drupal.org/node/3223395#s-shortcut).
