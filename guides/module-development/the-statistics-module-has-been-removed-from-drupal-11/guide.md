Introduced in branch: 11.0.x\
Introduced in version: 11.0.0\
Issue links: [#3341092](https://www.drupal.org/node/3341092)

The Statistics module is removed.

The Statistics module was deprecated in Drupal 10.3.0 and the module moved to contrib at [https://drupal.org/project/statistics](https://www.drupal.org/project/statistics).

If you need the functionality provided by the Statistics module, read the [recommendations for the Statistics module](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-statistics).
