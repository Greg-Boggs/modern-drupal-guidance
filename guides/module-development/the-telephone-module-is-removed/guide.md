Introduced in version: 12.0.0\
Issue links: [#3594199](https://www.drupal.org/node/3594199)

The Telephone module is removed.

The Telephone module was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/telephone](https://drupal.org/project/telephone)

If you need the functionality provided by the Telephone module, [read the recommendations for the Telephone module](https://www.drupal.org/node/3223395#s-telephone).
