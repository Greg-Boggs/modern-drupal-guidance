Introduced in branch: 12.0.x\
Introduced in version: 12.0.0\
Issue links: [#3586211](https://www.drupal.org/node/3586211)

The Toolbar module is removed.

The Toolbar module was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/toolbar](https://drupal.org/project/toolbar)

If you need the functionality provided by the Toolbar module, read the [recommendations for the Toolbar module](https://www.drupal.org/node/3223395#s-toolbar).

Core now uses the Navigation module.
