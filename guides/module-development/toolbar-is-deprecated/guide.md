Introduced in version: 11.5.0\
Issue links: [#3560123](https://www.drupal.org/node/3560123)

The Toolbar module is deprecated, it will be removed in 12.0.0.

If you want to keep using the functionality provided by Toolbar, read the [recommendations for Toolbar](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-toolbar).
