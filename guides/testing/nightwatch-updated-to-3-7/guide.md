Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3371963](https://www.drupal.org/node/3371963)

Drupal's Nightwatch JavaScript testing dependency has been updated from 2.x to 3.7.x

See [Drupal's own nightwatch documentation](https://www.drupal.org/docs/develop/automated-testing/javascript-testing-using-nightwatch) and [Nightwatch's update guide](https://nightwatchjs.org/guide/overview/whats-new-in-v3.html) for details of how to use it.

This change will only affect module developers with existing nightwatch tests.
