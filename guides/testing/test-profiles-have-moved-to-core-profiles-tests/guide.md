Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3490493](https://www.drupal.org/node/3490493)

All install profiles used for testing have moved from the `core/profiles` to `core/profiles/tests`. In the unlikely event that a contrib or custom test depends on the path to an install profile it will need updating for 11.1 compatibility.

*Source: [Test profiles have moved to core/profiles/tests](https://www.drupal.org/node/3490626), a Drupal core change record by [alexpott](https://www.drupal.org/user/157725) on drupal.org, licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).*
