Introduced in branch: 11.5.x\
Introduced in version: 11.5.0\
Issue links: [#3576670](https://www.drupal.org/node/3576670)

The Claro theme is deprecated, it will be removed in 12.0.0.

If you want to keep using the functionality provided by Claro, read the [recommendations for Claro](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-claro).
