Introduced in version: 11.5.0\
Issue links: [#3595083](https://www.drupal.org/node/3595083)

The Olivero theme is deprecated, it will be removed in 12.0.0.

If you want to keep using the functionality provided by Olivero, read the [recommendations for Olivero](https://www.drupal.org/docs/core-modules-and-themes/deprecated-and-obsolete-modules-and-themes#s-olivero).
