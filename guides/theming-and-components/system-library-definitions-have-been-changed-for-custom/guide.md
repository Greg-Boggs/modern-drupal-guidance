Introduced in branch: 11.5.x\
Introduced in version: 11.5.0\
Issue links: [#3619507](https://www.drupal.org/node/3619507), [#3467488](https://www.drupal.org/node/3467488)

CSS files in system module's 'base' library have been moved from 'component' to 'base'.

Themes or modules that alter or override the `system/base` library definition may need to update for the new library definition.
