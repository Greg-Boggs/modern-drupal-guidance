Introduced in version: 12.0.0\
Issue links: [#3584639](https://www.drupal.org/node/3584639)

The Claro theme is removed.

The Claro theme was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/claro](https://drupal.org/project/claro)

If you need the functionality provided by the Claro theme, read the [recommendations for the Claro theme](https://www.drupal.org/node/3223395#s-claro).
