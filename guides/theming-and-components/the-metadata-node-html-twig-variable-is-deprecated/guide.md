Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3458612](https://www.drupal.org/node/3458612)

The 'metadata' variable for node templates is no longer printed by the default node template.

If contributed code was relying on this variable, consider adding a computed field or another mechanism to add markup to the node instead.
