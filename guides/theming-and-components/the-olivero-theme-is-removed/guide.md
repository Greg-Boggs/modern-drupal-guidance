Introduced in version: 12.0.0\
Issue links: [#3595089](https://www.drupal.org/node/3595089)

The Olivero theme is removed.

The Olivero theme was deprecated in Drupal 11.5.0 and the module moved to contrib at [https://drupal.org/project/olivero](https://drupal.org/project/olivero)

If you need the functionality provided by the Olivero theme, read the [recommendations for the Olivero theme](https://www.drupal.org/node/3223395#s-olivero).
