Introduced in branch: 11.1.x\
Introduced in version: 11.1.0\
Issue links: [#3458183](https://www.drupal.org/node/3458183)

The teaser variable passed to node templates is deprecated in 11.1.0 and will be removed in 12.0.0. Node templates already have a 'view_mode' variable as well as theme suggestions, which allow specific theming if the teaser view mode is used.
