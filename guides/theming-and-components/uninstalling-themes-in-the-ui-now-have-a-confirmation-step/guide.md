Introduced in branch: 11.4.x\
Introduced in version: 11.4.0\
Issue links: [#3096170](https://www.drupal.org/node/3096170)

When uninstalling a theme in the UI a confirmation form will now be presented outlining the configuration that will be removed.

This grants the ability to cancel the uninstall.

*Source: [Uninstalling themes in the UI now have a confirmation step](https://www.drupal.org/node/3582449), a Drupal core change record by [nicxvan](https://www.drupal.org/user/531480) on drupal.org, licensed under [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/).*
